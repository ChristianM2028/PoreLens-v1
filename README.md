# PoreLens

A zero-install browser prototype for pressure-dependent RASPA trajectory forensics. It presents RDF trend detection, inferred Lennard–Jones attribution, and pore-contact evidence in one workspace.

## Run locally

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`. Files selected in the interface remain local to the browser; the current prototype indexes file names and types and demonstrates the intended analysis workflow with a built-in C5 example.
